Add/Remove Field (All Batchmates)

Adds or deletes one field across every document in the "batchmates" collection at once. This only touches "batchmates" — if the field is also shown in the directory (fullName, gender, birthday, primaryMobile, sports, clubs, skills, campusIndexNumber, photoUrl), update "batchmatesPublic" separately. This cannot be undone from here, so double-check the field name before applying.

Letters, numbers and underscores only, starting with a letter — matches how existing fields (e.g. fullName, bloodGroup) are named.

Manage Profile Fields

Controls the Dashboard's detail cards (Person, Campus, Contact, etc.) — their order, titles, and fields. Mark a field "Public" to also show it on that batchmate's card in the Home directory popup; turning Public off removes it from there again. Changes only apply after you tap Save.

"Re-sync Directory Now" re-applies the current saved settings (including prestige levels) to every batchmate's directory entry, without changing anything below — useful after bulk-editing profiles elsewhere.
